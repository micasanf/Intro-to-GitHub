# Intro-to-GitHub

This repository was created as part of an assignment to learn the basics of **Git** and **GitHub**. It demonstrates how to create a repository, manage files, and use Git locally to push changes to GitHub.

## Purpose

The goal of this repository is to practice the core Git and GitHub workflow, including:
- Creating a GitHub repository
- Writing and updating a README file
- Uploading files to a repository
- Cloning a repository to a local machine
- Making changes, committing them, and pushing them back to GitHub

## Contents

This repository includes sample files uploaded as part of the assignment, along with this README describing the project.

## What I Learned

- **Git** is a version control system used to track changes in files over time.
- **GitHub** is a platform that hosts Git repositories online and enables collaboration.
- Key Git concepts include repositories, commits, branches, and pull requests.
- The basic local workflow is: `clone` → edit files → `add` → `commit` → `push`.
